Entry for the [make.fun](https://make.fun) competition
**"Worst Fix Ever: Funniest Commit Message"**
(`u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722`).

## What it does

`main.py` writes a single line to `/output/entry.txt`: a commit message
for a bug fix that made everything worse — the bug got fixed so hard it
was promoted to a feature and now outranks the engineer who fixed it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: the same single line on every run, at most
100 characters, UTF-8, one line.
